# Historisch experiment — verkeerde data voor de cursusinlevering

Deze resultaten gebruiken de volledige UCI-download van 61.069 rijen, niet het
voorgeschreven geüploade cursusbestand van 5.000 rijen. De soortgebonden vergelijking
en het hier gekozen model zijn **niet de finale modelkeuze**. De bestanden blijven
uitsluitend bewaard voor herkomstcontrole.

Gebruik [het gecorrigeerde hoofdrapport](../09_vergelijkingsrapport.md) en
[MushroomFinal](../../MushroomFinal/README.md). Deel bronrijen van het cursusbestand
niet door 353: de soortgroepering van dit experiment is daar niet op toepasbaar.
